# APPLYING FAIL

**How to Apply the Free AI License (FAIL) to Your Project**

Version: 1.0.0

---

# Overview

This guide explains how to license your Artificial Intelligence project under the **Free AI License (FAIL)**.

Applying FAIL takes only a few minutes and helps make your project part of an open ecosystem dedicated to accessible and collaborative AI.

---

# Step 1 — Add the License

Copy the official `LICENSE` file from the FAIL repository into the root of your project.

Example:

```
my-project/
├── LICENSE
├── README.md
├── src/
└── ...
```

Do not modify the legal text of the license.

---

# Step 2 — Reference FAIL in your README

Add a License section.

Example:

```markdown
## License

This project is licensed under the **Free AI License (FAIL) v1.0**.

See the [LICENSE](LICENSE) file for the complete legal text.
```

---

# Step 3 — Add FAIL.md

Create a file named:

```
FAIL.md
```

This file describes how your project complies with FAIL.

Example:

```text
Project Name: My AI

License: FAIL v1.0

Compliance Level:
FAIL Core

Repository:
https://github.com/example/project

Website:
https://example.com
```

---

# Step 4 — Add FAIL.toml

Create a machine-readable manifest.

Example:

```toml
[fail]
version = "1.0"

[project]
name = "My AI"
license = "FAIL"

[organization]
name = "Example Organization"
```

This allows automated tools to identify projects licensed under FAIL.

---

# Step 5 — Keep Attribution

Preserve copyright notices and attribution required by the license.

Example:

```
Copyright (c) 2026 Example Organization

Licensed under the Free AI License (FAIL).
```

---

# Step 6 — Document Your AI

Whenever possible, include documentation describing:

- Purpose
- Model architecture
- Datasets
- Limitations
- Intended use
- Safety considerations

Transparency benefits both developers and users.

---

# Step 7 — Encourage Community Contributions

Community improvements are welcome.

Contributing fixes, documentation, or enhancements is **encouraged but not required** by the FAIL license.

---

# Step 8 — Register Your Project (Optional)

You may register your project in the official FAIL Registry.

Benefits include:

- Public visibility
- Registry ID
- Ecosystem discovery
- Community recognition
- Future certification eligibility

---

Before publishing, verify that your project includes:

- Attribution

- Security policy (recommended)
